# TypeScript Learning 📘

My hands-on journey through TypeScript, coming from a JavaScript/MERN background.

## Topics Covered
- Basic types, unions, and literal types
- Interfaces vs type aliases
- Functions and generics
- Classes and access modifiers
- Type narrowing and type guards
- Utility types (Partial, Pick, Omit, Record)
- tsconfig and strict mode



## Run Locally
git clone https://github.com/HarisShahnawaz/TypeScript-Learning
cd TypeScript-Learning
npm install
npm run build
